# 🌐 صفحه ارتباطی کرمان تجربه (Kerman Tajrobe Links)

این پروژه یک صفحه‌ی مستقل (لندینگ پیج) برای مجموعه «کرمان تجربه» است که تمام راه‌های ارتباطی و شبکه‌های اجتماعی این مجموعه را در یک صفحه‌ی مدرن، مینیمال و با طراحی سینماتیک گردآوری کرده است. 

هدف از این صفحه، ارائه یک تجربه کاربری روان به کاربران برای دسترسی سریع به پیام‌رسان‌ها و راه‌های تماس با مجموعه است.

# ویژگی های کلیدی

- **طراحی مدرن و شیشه‌ای (Glassmorphism):** استفاده از افکت‌های نیمه‌شفاف، بلور (Backdrop Blur) و نورپردازی پویا.
- **پس‌زمینه سینماتیک:** افکت‌های گرادیانت متحرک (Aurora) در پس‌زمینه برای ایجاد حس عمق و پویایی.
- **کاملاً ریسپانسیو (Responsive):** بهینه‌سازی شده برای تمام دستگاه‌ها (در موبایل به صورت تک‌ستونی و در دسکتاپ به صورت دو ستونی و متقارن).
- **انیمیشن‌های روان:** افکت‌های ورود (Fade-in) و تعامل‌های زیبا هنگام قرار گرفتن موس روی کارت‌ها (Hover Effects).
- **دسترسی‌پذیری (Accessibility):** استفاده از فونت استاندارد فارسی (وزیرمتن) و تنظیمات راست‌چین (RTL) اصولی.
- **پیاده‌سازی مدرن:** استفاده از فریم‌ورک Next.js و آیکون‌های SVG حرفه‌ای.

## 🛠 تکنولوژی‌های استفاده شده

- **فریم‌ورک اصلی:** [Next.js](https://nextjs.org/) (نسخه App Router)
- **زبان:** JavaScript / JSX
- **استایل‌دهی:** CSS Modules / Global CSS
- **آیکون‌ها:** [React Icons](https://react-icons.github.io/react-icons/)
- **فونت:** Vazirmatn (از طریق next/font/google)

🚀 راه‌اندازی و اجرای پروژه (Local Development)

برای اجرای این پروژه روی سیستم خودتان، مراحل زیر را طی کنید:

۱. پیش‌نیازها:
مطمئن شوید که Node.js (نسخه 18 یا بالاتر) روی سیستم شما نصب است.

۲. نصب وابستگی‌ها:
در مسیر اصلی پروژه، ترمینال (CMD یا Terminal) را باز کنید و دستور زیر را اجرا کنید:

```bash
npm install
```

۳. اجرای محیط توسعه:

```bash
npm run dev
```

پس از اجرا، آدرس http://localhost:3000 را در مرورگر خود باز کنید.

📦 ساخت نسخه نهایی (Production Build)

برای اینکه از سرعت و بهینه‌سازی نهایی پروژه مطمئن شوید، دستور زیر را اجرا کنید:

```bash
npm run build
```

سپس برای اجرای نسخه بهینه‌شده:

```bash
npm start
```
